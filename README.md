## 👨‍💻 About Me

Saya **Akmal Ikhsan**, seorang Web Developer yang suka membangun antarmuka yang bersih, cepat, dan nyaman dipakai. Perjalanan saya dimulai dari dasar **HTML, CSS, dan JavaScript**, lalu berkembang ke **React** untuk membangun aplikasi yang lebih dinamis, dengan **Supabase** sebagai backend, **Git** untuk version control, dan **Linux** sebagai lingkungan kerja sehari-hari.

Saat ini saya sedang mendalami **pengembangan aplikasi mobile dengan Flutter**. Di luar coding, saya juga menikmati desain visual menggunakan **Krita**.

- 🌱 Sedang belajar: Flutter & pengembangan aplikasi mobile
- 🛠️ Fokus: Web development dengan HTML, CSS, JavaScript, React, dan Supabase
